# 9维度评分细则

本文件是 `pre-flash-sale-analysis` skill 的评分参考。打分时读取本文件获取每个维度的具体评分标准。

## 评分总览

9个维度，每个维度0-10分，总分90分。库存维度兼做门槛判定（<4分则不参与推荐排名）。

---

## 1. 销量基础（10分）

**数据源**：领星ERP `query_product_performance_asin_lists` 的 `volume` 字段（当月）

| 月销量 | 得分 | 说明 |
|--------|------|------|
| > 2000 | 10 | 高销量品，秒杀增量空间大 |
| 1500-2000 | 9 | |
| 800-1500 | 7-8 | 中等销量 |
| 300-800 | 4-6 | 低销量，秒杀需靠折扣拉动 |
| 100-300 | 2-3 | |
| < 100 | 1 | 极低销量，秒杀风险高 |

**修正规则**：如果领星月销量与SIF的 `bought_in_past_month` 差异>3倍，取较低值并标注"数据存疑"。

---

## 2. 流量趋势（10分）

**数据源**：SIF `ops_get_asin_traffic_trend` 的30天变化

| 趋势类型 | 得分 | 判定依据 |
|----------|------|----------|
| sharp_growth | 10 | 30天流量增长>50% |
| mild_growth | 8 | 30天流量增长10-50% |
| stable | 6 | 30天流量波动<10% |
| mild_decline | 4 | 30天流量下降10-30% |
| sharp_decline | 2 | 30天流量下降>30% |

**修正规则**：如果SIF流量数据不可用，用领星近3月月销量环比趋势替代（增长=8，平稳=6，下降=4）。

---

## 3. BSR走势（10分）

**数据源**：SIF `market_get_asin_profile` 的 `bsr_list` + `ops_get_asin_traffic_trend`

| BSR变化 | 得分 | 说明 |
|---------|------|------|
| 改善>50% | 10 | 排名大幅上升 |
| 改善20-50% | 8 | |
| 改善5-20% | 7 | |
| 持平(±5%) | 6 | |
| 下滑5-20% | 4 | |
| 下滑20-50% | 2 | |
| 下滑>50% | 1 | 排名崩溃 |

---

## 4. 价格带（10分）

**数据源**：SIF `market_get_asin_profile` 的 `price` 字段

| 价格区间 | 得分 | 说明 |
|----------|------|------|
| $5.00-$8.00 | 9-10 | 秒杀黄金价格带，折扣后$3.5-$5.6，决策门槛极低 |
| $8.01-$10.00 | 7-8 | 秒杀价$5.6-$7.0，仍具吸引力 |
| $10.01-$15.00 | 4-5 | 秒杀价$7-$10.5，需产品力支撑 |
| $15.01-$25.00 | 3 | 秒杀价$10.5-$17.5，决策周期长 |
| > $25.00 | 2 | 高客单价，秒杀转化率偏低 |
| < $5.00 | 5 | 价格过低毛利可能不足 |

**修正规则**：$5.99以下低价品如果利润空间不足（毛利率<15%），价格分降2分。

---

## 5. 评论基础（10分）

**数据源**：SIF `market_get_asin_profile` 的 `rating_num` + `star_rating`

| 评论数 | 星级≥4.5 | 星级4.0-4.5 | 星级<4.0 |
|--------|----------|-------------|----------|
| > 2000 | 10 | 8 | 5 |
| 1000-2000 | 9 | 7 | 4 |
| 500-1000 | 8 | 6 | 3 |
| 200-500 | 6 | 5 | 2 |
| 50-200 | 4 | 3 | 1 |
| < 50 | 2 | 1 | 0 |

**修正规则**：父ASIN评论数和子ASIN评论数可能差异大，取子ASIN合计评论数。

---

## 6. 季节时机（10分）

**数据源**：SIF `market_get_keyword_root_trend` 的过去12月搜索量趋势

| 时机类型 | 得分 | 判定依据 |
|----------|------|----------|
| 旺季峰值期 | 10 | 搜索量处于年度最高位（>年均值150%） |
| 旺季爬坡期 | 8-9 | 搜索量环比上升，距峰值还有1-3月 |
| 常青品类 | 6-7 | 全年波动<30%，无明确季节性 |
| 淡季回升期 | 5-6 | 搜索量从低谷开始回升 |
| 淡季低谷期 | 3-4 | 搜索量处于年度低位 |
| 旺季衰退期 | 2-3 | 搜索量从峰值快速下降 |

**季节性判定方法**：
1. 取过去12个月搜索量数据。
2. 计算年均值。
3. 当前月搜索量 > 均值×1.5 → 旺季；< 均值×0.6 → 淡季。
4. 环比上月上升>20% → 爬坡期；下降>20% → 衰退期。

---

## 7. 利润空间（10分）

**数据源**：Sorftime `product_detail` 的毛利率；或领星ERP的 `gross_margin` 字段

| 毛利率 | 得分 | 说明 |
|--------|------|------|
| > 50% | 10 | 秒杀折扣空间充裕 |
| 40-50% | 9 | |
| 30-40% | 7-8 | 秒杀85折后仍有利润 |
| 20-30% | 5-6 | 秒杀85折后利润微薄 |
| 10-20% | 3 | 秒杀可能亏本 |
| < 10% | 1 | 秒杀必然亏本 |
| 无数据 | 5 | 基准分，标注"利润数据缺失" |

**修正规则**：秒杀价 = 原价 × 0.85（85折），如果秒杀价 < 产品成本+FBA费用+佣金，利润分最高给3分。

---

## 8. 综合动量（10分）

**数据源**：流量趋势 + BSR走势 + 销量环比三者综合

| 动量类型 | 得分 | 判定依据 |
|----------|------|----------|
| 三者同向上升 | 9-10 | 流量↑ + BSR↑ + 销量↑ |
| 两项上升一项平稳 | 7-8 | |
| 一项上升两项平稳 | 6 | |
| 三项平稳 | 5 | |
| 一项下降 | 3-4 | |
| 两项下降 | 2 | |
| 三者同向下降 | 1 | 产品衰退期 |

**动量判定方法**：
1. 流量趋势：SIF 30天变化方向。
2. BSR走势：SIF 30天BSR变化方向。
3. 销量环比：领星当月vs上月，变化>15%计为上升/下降。

---

## 9. 库存充足度（10分）

**数据源**：领星ERP `fba_fulfillable_quantity` ÷ `volume`

| 库销比 | 得分 | 门槛判定 |
|--------|------|----------|
| ≥ 10月 | 10 | ✅ 通过（库存极其充裕） |
| 5-10月 | 9 | ✅ 通过 |
| 3-5月 | 7-8 | ✅ 通过 |
| 2.5-3月 | 6 | ✅ 通过（达标） |
| 2.0-2.5月 | 4 | ⚠ 临界 |
| 1.5-2.0月 | 3 | ❌ 不通过 |
| 1.0-1.5月 | 2 | ❌ 不通过 |
| < 1.0月 | 1 | ❌ 严重不足 |

**门槛判定逻辑**：
- 得分<4分 → 门槛标记 ❌，不参与推荐排名。
- 得分=4分 → 门槛标记 ⚠，参与排名但标注风险。
- 得分≥6分 → 门槛标记 ✅，正常参与排名。
