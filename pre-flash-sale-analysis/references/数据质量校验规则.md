# 数据质量校验规则

本文件是 `pre-flash-sale-analysis` skill 的数据质量保障参考。当领星ERP数据存疑或MCP连接异常时读取本文件。

## 领星ERP数据新鲜度校验

### 问题背景

领星MCP的Key有效期有限。Key过期后，MCP不会报错，而是返回缓存数据或默认值。这些失真数据与真实数据差异可达3-30倍。

**实测案例（2026-09-03）**：

| ASIN | 过期Key数据 | 新鲜数据 | 差异倍数 |
|------|------------|----------|----------|
| B095H2TX95 FBA可售 | 24,295件 | 853件 | 28倍 |
| B0DJSKJ3R9 8月销量 | 230件 | 506件 | 2.2倍 |
| B0CJ4SPFGZ 8月销量 | 652件 | 1,649件 | 2.5倍 |
| B093GC1P2Q FBA可售 | 985件 | 3,362件 | 3.4倍 |

### 校验流程

1. **连接确认**：调用 `help` 工具，检查返回的 `catalogVersion` 字段。如果字段存在且格式为 `lingxing-mcp-YYYYMMDD-vN`，说明连接正常。如果返回空或格式异常，标注"领星连接异常"。

2. **数据量检查**：查询返回的 `list` 数组长度。如果用户提供了N个ASIN但返回结果明显少于N（如提供11个只返回7个），可能是因为：
   - `mids` 参数限制了国家 → 去掉 `mids` 重查
   - 部分ASIN在ERP中不存在 → 标注"ERP中未找到"
   - Key过期导致部分数据丢失 → 重新连接

3. **交叉验证**：将领星月销量与SIF的 `bought_in_past_month` 对比。
   - 差异<2倍：数据可信
   - 差异2-3倍：标注"数据可能有偏差"
   - 差异>3倍：标注"领星数据可能失真，建议重新连接ERP"

4. **趋势合理性**：检查领星月度趋势是否合理。
   - 如果所有月份销量完全相同 → 可能是缓存数据
   - 如果某月销量为0但其他月正常 → 可能是数据缺失
   - 如果趋势与SIF关键词搜索量趋势完全背离 → 数据存疑

### 降级策略

当领星数据不可用或失真时：

| 场景 | 降级方案 |
|------|----------|
| 领星MCP完全不可用 | 仅用SIF数据，库存维度用SIF的BSR排名推算相对需求，无法计算库销比，标注"库存门槛无法判定" |
| 领星数据部分失真 | 对失真ASIN标注"数据存疑"，用SIF的 `bought_in_past_month` 替代月销量 |
| 领星返回部分ASIN | 对缺失ASIN用 `asin` 搜索字段替代 `parent_asin`，或不限制 `mids` 重查 |

## SIF数据校验

### 数据延迟
- SIF周数据以周日为每周第一天。
- 当周数据可能因T+1延迟不可用（通常周一-周二查不到上周完整数据）。
- 如果查询返回空或数据不完整，标注"SIF数据延迟，建议隔日重查"。

### 验证链接
- SIF工具返回的 `render_footer` 字段包含官网验证链接。
- 报告末尾必须保留该链接原文，不能省略。
- 如果 `render_footer` 缺失，标注"SIF验证链接缺失"。

## Sorftime数据校验

- Sorftime的 `product_detail` 可能不覆盖所有ASIN。
- 如果返回为空，标注"Sorftime无此ASIN数据"，利润维度给5分基准分。
- Sorftime数据不做强制校验，作为辅助参考。

## 数据质量等级标注

报告中对每个ASIN标注数据质量等级：

| 等级 | 判定 | 标注方式 |
|------|------|----------|
| A | 领星+SIF数据均正常，交叉验证通过 | 无标注 |
| B | 领星或SIF有一方数据存疑 | 标注"数据可能有偏差" |
| C | 领星数据失真，仅用SIF数据 | 标注"领星数据失真，仅用SIF" |
| D | 领星和SIF均不可用 | 标注"数据源不可用，分析结果仅供参考" |

## 领星MCP查询参数备忘

### 必填参数
- `turn_on_summary`: `1`（不填会报错 "turn_on_summary 不能为空"）
- `offset`: `0`
- `length`: `50`（默认20不够）
- `start_date` / `end_date`: 格式 `yyyy-MM-dd`

### 推荐参数
- `search_field`: `parent_asin`（父ASIN搜索）
- `summary_field`: `parent_asin`（按父ASIN汇总）
- `date_view_type`: `month`（月度视图）
- `date_view_order_type`: `2`（按ASIN分组）
- `currency_code`: `USD`
- `sort_field`: `volume`
- `sort_type`: `desc`

### 注意事项
- **不要设置 `mids` 参数**（限制国家会导致部分ASIN返回空）
- 返回数据量大（11个ASIN×8月 ≈ 1MB），需要用PowerShell解析JSON
- JSON嵌套结构：`data.data.data.list[]`，每个item含 `parent_asin`、`rdate`、`volume`、`available_inventory`（对象）
- `available_inventory` 是嵌套对象，包含 `afn_fulfillable_quantity`、`available_inventory`、`afn_inbound_receiving_quantity`
